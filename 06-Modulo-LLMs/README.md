# Módulo opcional: LLMs abiertos (sesión extra)

Fuera del núcleo obligatorio. Se imparte solo si hay tiempo y se confirma. Duración propuesta: 4 horas.

## Contenido
Pesos, tokenizador, contexto, motor de inferencia, parámetros de generación, cuantización, recursos y licencias,
separación entre servidor del LLM y aplicación cliente, evaluación básica de respuestas.

## Práctica
Ejecutar un modelo pequeño con el motor elegido (Ollama como propuesta inicial), consumirlo desde Python,
conectarlo a una API, probar instrucciones, parámetros, streaming y fallos.

## Tarea
Opcional: adaptar la aplicación consumidora a una funcionalidad del caso y documentar respuestas y limitaciones.

## Pendiente
Motor y modelo definitivos; alternativa compartida para quien no pueda ejecutarlo; RAG como ampliación posterior.
