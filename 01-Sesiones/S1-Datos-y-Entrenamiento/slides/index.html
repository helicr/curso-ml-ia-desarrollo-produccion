¿Volverá este cliente en los próximos 90 días?

Los datos

La decisión que apoya

Medir como se va a usar

¿Por qué partir por tiempo?

Partición temporal (test)

AUC 0.796

Entrena con cortes pasados, evalúa en cortes posteriores.

Partición aleatoria (5 semillas)

AUC 0.766

Rango 0.761–0.770. Mezcla clientes de todas las fechas.

Lectura honesta: aquí la aleatoria dio un valor más bajo, no más alto. No es una fuga que infle la métrica en este caso.
Se elige la temporal porque se parece al uso real: predecir el futuro con lo aprendido del pasado. Además, la tasa de recompra cambia (48 → 35 → 38 %), algo que una mezcla aleatoria esconde.

Entrenamiento

Tres modelos, una decisión

ModeloAUC trainAUC validAUC testPrec. media test
Referencia (sin aprender)0.5000.5000.5000.380
Regresión logística0.7400.7860.7960.735
Gradient boosting0.8420.7610.7810.718
El gradient boosting «sabe» mucho más del pasado (0,842) pero generaliza peor: sobreajuste. Gana la regresión logística, más simple.
Con la muestra del curso (23 070 filas) los valores serán distintos: regresión logística valid 0.698 · test 0.747. Eso es esperado, no un error.

Dato completo: 1 067 371 filas. Regla: se elige con valid, se informa test una sola vez.
