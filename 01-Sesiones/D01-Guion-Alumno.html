Cómo se abre el proyecto en VS Code

PasoQué hacer
DóndeSe clona en C:\cursos (carpeta nueva). El proyecto queda en C:\cursos\curso-ml-ia-desarrollo-produccion.
CómoTerminal (CMD o PowerShell): cd C:\cursos, git clone --branch develop https://github.com/helicr/curso-ml-ia-desarrollo-produccion.git, cd curso-ml-ia-desarrollo-produccion, git branch --show-current (debe decir develop) y code ..
Abrir la carpetaSe abre la carpeta del repositorio, no un archivo suelto (Archivo → Abrir carpeta, o code .). Si VS Code pregunta si confías en los autores, acepta: la clonaste tú.
IntérpreteCtrl+Mayús+P → «Python: Select Interpreter» → env-ia-mlops. Debe verse en la barra inferior.
Terminal de VS CodeCtrl+ñ (o Terminal → Nueva terminal): conda activate env-ia-mlops y cd 04-Proyecto-Base. Con el Anaconda Prompt también vale.
CuadernosAbre un .ipynb → «Seleccionar kernel» (arriba a la derecha) → Python Environments → env-ia-mlops.
NovedadesPara traer cambios del repositorio: git pull desde la carpeta del curso.
