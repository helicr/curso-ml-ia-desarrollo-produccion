1 · Qué construimos · ML e IA: de desarrollo a producción · S5 · extra

Una interfaz web que une dos servidores MCP y un LLM

Laboratorio paso a paso: preparas el entorno, arrancas la interfaz (http://127.0.0.1:8095), la recorres pestaña a pestaña con capturas reales y la pruebas. Lo que ves sale de las herramientas MCP; el LLM solo conversa.

FastAPI2 servidores MCP por stdioSQLite o BigQueryModelo @championLLM aparte (Ollama)6 pestañas

Qué vas a hacer

  • Arrancarla en Windows (cmd y PowerShell) o en un Codespace.
  • Promover una versión del modelo y ver cómo cambia lo que responde.
  • Preguntar a un LLM pequeño y comprobar sus herramientas en la traza.

Cómo se sigue

  • ← → avanzan · O índice · S notas del profesor · F pantalla completa.
  • Cada orden tiene su botón ⧉; cada captura se amplía con la lupa (Esc la cierra).
  • Cada captura dice qué clic o qué entrada la produce.

Honestidad

  • Las capturas son reales, hechas en Windows con qwen2.5:0.5b.
  • Lo que no se pudo probar (Codespace, Linux, BigQuery desde la interfaz, un LLM mayor) lleva «sin verificar».

1 · Qué construimos · quién habla con quién

El navegador solo habla con FastAPI; FastAPI lanza los dos servidores MCP y llama al LLM aparte

Un solo proceso web

  • app.py arranca los dos servidores de fuentes/ como procesos hijos (stdio) y guarda toda llamada en una traza.
  • Solo escucha en 127.0.0.1.

Los datos y el modelo

  • mcp-datos-master: 7 herramientas, SQLite o BigQuery.
  • mcp-modelo-retencion: 4 herramientas; carga lo que mande @champion.

El LLM

  • Es otro servidor (/v1/chat/completions): la interfaz le ofrece las herramientas y ejecuta las que pide.
  • Sin LLM, el resto funciona.

Fuente: ui/app.py (docstring y clase Puente) y ui/README.md; recuento de herramientas: pestaña Explorador MCP (captura 11).

2 · Preparar y arrancar · host extra

En un Codespace la página llega con otro nombre de host: hay que admitirlo antes de arrancar

Codespace / Linux (bash), desde la carpeta ui
$ export CURSO_UI_HOSTS="*.app.github.dev"
$ python -m uvicorn app:app --port 8095
  • Lo mismo que en Windows, desde la carpeta ui.
  • Abre el puerto 8095 reenviado (pestaña «Puertos»).
  • Sin esa variable, la interfaz rechaza el host con 400 (protección contra «DNS rebinding»).

Sin verificar Codespace y Linux no se han probado: solo Windows.

Por qué hace falta

  • app.py solo atiende 127.0.0.1, localhost y los hosts de CURSO_UI_HOSTS.
  • En Windows el 400 con otro host sí está probado (test_solo_acepta_hosts_locales).
  • Lo que no está probado es el reenvío del puerto en un Codespace.

Si falla

  • La página no abre o da 400: revisa CURSO_UI_HOSTS y que el puerto 8095 esté reenviado.
  • Ollama no existe en un Codespace sin instalarlo: la pestaña Pregunta avisará y el resto funciona.

Fuente: ui/README.md (Codespace / Linux) y ui/pruebas/test_interfaz.py.

3 · Recorrido por la interfaz · deslizadores y delta

Mover una variable da otra cifra, pero no un cliente real ni una causa

Qué debes ver

Advertencia honesta: en este modelo la probabilidad sube con la recencia (más días sin comprar, más probabilidad), contra la intuición; no se ha investigado por qué y la relación no es causal. Las variables van juntas: una sola no es un cliente real.

Ocho ataques de ejemplo: la capa 2 los frena todos antes de llegar al motor

Ataque (botón)SQL que envíaMensaje de la capa 2
DROPDROP TABLE master_clientesSolo se admiten consultas que empiecen por SELECT (o WITH).
UPDATEUPDATE master_clientes SET pais = 'Nowhere'Solo se admiten consultas que empiecen por SELECT (o WITH).
