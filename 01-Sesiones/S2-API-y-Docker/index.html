S2API y Docker

4 h · 01-Sesiones/S2-API-y-Docker · Material preparado

Del modelo guardado a un servicio: API con FastAPI cuyo contrato sale de la firma del modelo, errores 422/503/500, registros JSON, imagen Docker mínima, comparación de predicciones por todos los caminos y primer workflow de GitHub Actions. Tarea: llevar el modelo propio al mismo punto.

Probado en Linux y en GitHub Actions. Sin probar: el Codespace del curso (.devcontainer), Docker en un equipo propio y Windows. Los ejemplos de contenedores se ejecutaron con Docker real en GitHub Actions, no en un Codespace; lo que dicen de Cloud Run es solo la documentación de Google.
