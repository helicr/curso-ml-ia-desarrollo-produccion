S3Laboratorios: el servicio de S2, MLflow, GitHub Actions y una red neuronal

4 h · 01-Sesiones/S3-Despliegue-y-Redes-Neuronales · Material preparado

Cuatro laboratorios en el orden en que se construye el sistema: 1) el servicio de S2 (la API, la inferencia, las variables FS al vuelo y la interfaz); 2) MLflow (de dónde sale el modelo: runs, comparación, firma y versiones del registro); 3) GitHub Actions (cada cambio se comprueba solo: verde, rojo, verde); 4) extra: una red neuronal, ¿perro o gato?, registrada en MLflow como un modelo más. GCP se explica para llegar a S4 con Google Cloud activado. Tarea (avance 3): workflow con una prueba propia en rojo y en verde, y Google Cloud activado.

Cambio del 20/11/2026: la migración a GCP en vivo pasa a S4; la teoría y la guía de GCP de esta carpeta son material de preparación para S4. Las capturas son reales (Codespace del curso y GitHub Actions, 20/11/2026); en la red neuronal, entrenar, MLflow y predecir se capturaron en local. Las presentaciones de la sesión son los cuatro laboratorios (no hay slides/index.html). Minutos de cada bloque: en el guion.
