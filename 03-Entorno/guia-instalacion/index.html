Curso ML e IA · de desarrollo a producción

Prepara tu equipo Windows antes de S0

Instalas cinco programas y comprobamos que todo responde. Así, en clase solo verificamos. Docker y Kubernetes no se instalan: se usan en Codespaces.

Por validar Los comandos de winget y los identificadores de paquete se escribieron sin probarlos en un equipo Windows limpio y pueden haber cambiado. Los dos scripts sí se probaron con un winget falso (PowerShell 7 en Linux y CMD en Wine), pero no en Windows real. Si algo falla, usa el enlace de descarga del mismo paso y avisa al instructor.

1 · Elige tu ruta

Ruta sin instalación: Codespaces

Trabajas desde el navegador con un entorno en la nube que ya trae Python, Git y Docker.

  1. Crea o abre tu cuenta de GitHub: github.com/signup.
  2. Abre el Codespace del curso desde el repositorio: helicr/curso-ml-ia-desarrollo-produccion → botón Code → pestaña Codespaces.
  3. Para Google Cloud usa Cloud Shell desde console.cloud.google.com (botón de terminal arriba a la derecha): no necesitas instalar gcloud.
Pendiente El Codespace preconfigurado del curso aún no está publicado. Con esta ruta no se instala nada en tu equipo, pero Miniconda y el visor de SQLite se sustituyen por lo que traiga el Codespace. Quedan sujetos a la cuota gratuita de GitHub, que conviene revisar.

2 · Elige cómo instalar

¿Qué terminal prefieres?

Ambos caminos terminan igual: el script de verificación genera un informe que puedes pegar en el diagnóstico de S0.

Si algo falla

«winget no se reconoce como comando»

Instala o actualiza «Instalador de aplicación» desde Microsoft Store y abre una terminal nueva. Si no puedes, usa el enlace de descarga de cada paso manual.

PowerShell: «No se puede cargar el archivo porque la ejecución de scripts está deshabilitada»

Ejecuta el script con powershell -ExecutionPolicy Bypass -File ... como indica la guía. Esa opción vale solo para esa ejecución y no cambia la configuración de tu equipo. Si prefieres no usarla, usa la versión CMD del script.

CMD: «'instalar_entorno.cmd' no se reconoce como un comando»

Ejecútalo con la ruta completa, tal como aparece en el paso (%USERPROFILE%\instalar_entorno.cmd), o muévete primero a la carpeta donde lo guardaste con cd.

Windows muestra «Windows protegió su PC» al ejecutar el script

Puede aparecer con archivos descargados. Léelo antes (está completo en esta página); si confías en él, elige «Más información» y «Ejecutar de todas formas». Si lo copiaste y pegaste en el Bloc de notas, normalmente no aparece.

Instalé algo y la terminal no lo encuentra (git, code, gcloud…)

Cierra la terminal y abre una nueva: el PATH se actualiza al abrir una ventana. Si sigue igual, reinicia el equipo.

«conda no se reconoce»

Abre «Anaconda Prompt (Miniconda3)» desde el menú Inicio y ejecuta ahí conda --version. Para usar conda en PowerShell, ejecuta una vez conda init powershell y abre una terminal nueva.

Pide permisos de administrador o el antivirus bloquea la instalación

Si tu equipo es corporativo, probablemente no puedas instalar. Usa la ruta sin instalación (Codespaces) y avisa al instructor antes de S0.

Qué enviar al instructor

El contenido de verificacion-entorno.txt (lo genera el script) y el mensaje de error completo. No envíes contraseñas ni tokens.

Script completo

Léelo antes de ejecutarlo. Solo usa winget para instalar Git, VS Code, Miniconda, DB Browser for SQLite y Google Cloud CLI, más las extensiones de VS Code. Con la opción de verificar no instala nada.

@echo off
rem ====================================================================
rem  Instala o verifica el software local del curso "ML e IA: de desarrollo
rem  a produccion" en Windows, desde el Simbolo del sistema (CMD).
rem
rem  ESTADO: la logica se probo con stubs bajo Wine (Linux). NO se ha probado
rem  en Windows real ni con winget real. Probar en un equipo limpio y confirmar
rem  los identificadores con: winget search nombre
rem
rem  Que hace, y solo esto:
rem    - Usa winget para instalar Git, Visual Studio Code, Miniconda,
rem      DB Browser for SQLite y Google Cloud CLI.
rem    - Instala las extensiones de VS Code del curso.
rem    - Con la opcion verificar no instala nada: comprueba y escribe un informe.
rem  No descarga nada que no sea de winget. No toca el registro ni pide
rem  contrasenas, tokens o claves.
rem
rem  Docker y Kubernetes NO se instalan: en el curso se usan en Codespaces.
rem  Docker Desktop local es opcional: opcion dockerdesktop.
rem
rem  Uso:
rem    instalar_entorno.cmd                    instala lo que falte
rem    instalar_entorno.cmd verificar          solo comprueba
rem    instalar_entorno.cmd sinconfirmacion    no pregunta antes de instalar
rem    instalar_entorno.cmd sinextensiones     no instala extensiones de VS Code
rem    instalar_entorno.cmd dockerdesktop      incluye Docker Desktop opcional
rem ====================================================================
setlocal EnableExtensions EnableDelayedExpansion

set "MODO=instalar"
set "CONFIRMAR=1"
set "EXTENSIONES=1"
set "DOCKER=0"
for %%A in (%*) do (
  if /i "%%~A"=="verificar"       set "MODO=verificar"
  if /i "%%~A"=="/verificar"      set "MODO=verificar"
  if /i "%%~A"=="sinconfirmacion" set "CONFIRMAR=0"
  if /i "%%~A"=="sinextensiones"  set "EXTENSIONES=0"
  if /i "%%~A"=="dockerdesktop"   set "DOCKER=1"
)

set "INFORME=%CD%\verificacion-entorno.txt"

echo.
echo === Entorno del curso ML e IA, Windows, CMD ===
if "%MODO%"=="verificar" (
  echo Modo verificacion: no se instala nada.
) else (
  echo Modo instalacion. Lee lo que hace este script antes de continuar.
)
echo.

rem ---------------- tabla de herramientas
rem  NOMBRE, ID de winget, CMD (comando), ALT (rutas alternativas), OBL (1 obligatoria)
set "NOMBRE_1=Git"
set "ID_1=Git.Git"
set "CMD_1=git"
set "ALT_1=%ProgramFiles%\Git\cmd\git.exe"
set "ALT2_1="
set "ALT3_1="
set "OBL_1=1"

set "ID_2=Microsoft.VisualStudioCode"
set "CMD_2=code"
set "ALT_2=%LOCALAPPDATA%\Programs\Microsoft VS Code\bin\code.cmd"
set "ALT2_2=%ProgramFiles%\Microsoft VS Code\bin\code.cmd"
set "ALT3_2="
set "OBL_2=1"

set "NOMBRE_3=Miniconda"
set "ID_3=Anaconda.Miniconda3"
set "CMD_3=conda"
set "ALT_3=%USERPROFILE%\miniconda3\Scripts\conda.exe"
set "ALT2_3=%LOCALAPPDATA%\miniconda3\Scripts\conda.exe"
set "ALT3_3=%ProgramData%\miniconda3\Scripts\conda.exe"
set "OBL_3=1"

set "NOMBRE_4=DB Browser for SQLite"
set "ID_4=DBBrowserForSQLite.DBBrowserForSQLite"
set "CMD_4=db4s_no_esta_en_el_path"
set "ALT_4=%ProgramFiles%\DB Browser for SQLite\DB Browser for SQLite.exe"
set "ALT2_4="
set "ALT3_4="
set "OBL_4=1"

set "NOMBRE_5=Google Cloud CLI"
set "ID_5=Google.CloudSDK"
set "CMD_5=gcloud"
set "ALT_5=%LOCALAPPDATA%\Google\Cloud SDK\google-cloud-sdk\bin\gcloud.cmd"
set "ALT2_5="
set "ALT3_5="
set "OBL_5=1"

set "TOTAL=5"
if "%DOCKER%"=="1" (
  set "NOMBRE_6=Docker Desktop opcional"
  set "ID_6=Docker.DockerDesktop"
  set "CMD_6=docker"
  set "ALT_6=%ProgramFiles%\Docker\Docker\resources\bin\docker.exe"
  set "ALT2_6="
  set "ALT3_6="
  set "OBL_6=0"
  set "TOTAL=6"
)

rem ---------------- instalacion
if "%MODO%"=="instalar" (
  where winget >nul 2>&1
  if errorlevel 1 (
    echo No se encontro winget. Instala "Instalador de aplicacion" desde Microsoft Store, o sigue la guia manual con descargas.
    exit /b 1
  )
  for /l %%Z in (1,1,%TOTAL%) do (
    call set "NOMBRE=%%NOMBRE_%%Z%%"
    call set "ID=%%ID_%%Z%%"
    call set "CMD=%%CMD_%%Z%%"
    call set "ALT=%%ALT_%%Z%%"
    call set "ALT2=%%ALT2_%%Z%%"
    call set "ALT3=%%ALT3_%%Z%%"
    set "ENC="
    where !CMD! >nul 2>&1
    if not errorlevel 1 set "ENC=1"
    if not defined ENC if defined ALT  if exist "!ALT!"  set "ENC=1"
    if not defined ENC if defined ALT2 if exist "!ALT2!" set "ENC=1"
    if not defined ENC if defined ALT3 if exist "!ALT3!" set "ENC=1"
    if defined ENC (
      echo [ya instalado] !NOMBRE!
    ) else (
      set "HACER=1"
      if "!CONFIRMAR!"=="1" (
        set "RESP="
        set /p "RESP=Instalar !NOMBRE!? (s/N): "
        if /i not "!RESP!"=="s" if /i not "!RESP!"=="y" set "HACER=0"
      )
      if "!HACER!"=="1" (
        echo [instalando] !NOMBRE! - !ID!
        winget install --id !ID! -e --accept-source-agreements --accept-package-agreements
        if errorlevel 1 echo [fallo] !NOMBRE!: winget devolvio un error. Prueba la instalacion manual de la guia.
      ) else (
        echo [omitido] !NOMBRE!
      )
    )
  )

  if "!EXTENSIONES!"=="1" (
    set "CODEEXE="
    where code >nul 2>&1
    if not errorlevel 1 set "CODEEXE=code"
    if not defined CODEEXE if exist "%LOCALAPPDATA%\Programs\Microsoft VS Code\bin\code.cmd" set "CODEEXE=%LOCALAPPDATA%\Programs\Microsoft VS Code\bin\code.cmd"
    if not defined CODEEXE if exist "%ProgramFiles%\Microsoft VS Code\bin\code.cmd" set "CODEEXE=%ProgramFiles%\Microsoft VS Code\bin\code.cmd"
    if defined CODEEXE (
      for %%E in (ms-python.python ms-python.vscode-pylance ms-toolsai.jupyter ms-azuretools.vscode-containers ms-kubernetes-tools.vscode-kubernetes-tools ms-vscode-remote.remote-containers GitHub.codespaces) do (
        echo [extension] %%E
        call "!CODEEXE!" --install-extension %%E --force >nul 2>&1
      )
    ) else (
      echo VS Code no esta disponible todavia: cierra y abre la terminal y vuelve a ejecutar para instalar las extensiones.
    )
  )
  echo.
)

rem ---------------- verificacion e informe
set "WINVER="
for /f "delims=" %%V in ('ver') do if not defined WINVER set "WINVER=%%V"

>"%INFORME%" echo Informe de verificacion del entorno - curso ML e IA
>>"%INFORME%" echo Fecha: %DATE% %TIME%
>>"%INFORME%" echo Windows: !WINVER!
>>"%INFORME%" echo Interprete: CMD
>>"%INFORME%" echo No incluye credenciales ni datos personales.
>>"%INFORME%" echo.

set "FALTAN=0"
for /l %%Z in (1,1,%TOTAL%) do (
  call set "NOMBRE=%%NOMBRE_%%Z%%"
  call set "ID=%%ID_%%Z%%"
  call set "CMD=%%CMD_%%Z%%"
  call set "ALT=%%ALT_%%Z%%"
  call set "ALT2=%%ALT2_%%Z%%"
  call set "ALT3=%%ALT3_%%Z%%"
  call set "OBL=%%OBL_%%Z%%"
  set "ENC="
  set "VER="
  where !CMD! >nul 2>&1
  if not errorlevel 1 set "ENC=1"
  if defined ENC if /i not "!CMD!"=="db4s_no_esta_en_el_path" for /f "delims=" %%V in ('!CMD! --version 2^>^&1') do if not defined VER set "VER=%%V"
  if not defined ENC if defined ALT  if exist "!ALT!"  set "ENC=2"
  if not defined ENC if defined ALT2 if exist "!ALT2!" set "ENC=2"
  if not defined ENC if defined ALT3 if exist "!ALT3!" set "ENC=2"
  if "!ENC!"=="1" (
    echo [OK]    !NOMBRE!  !VER!
    >>"%INFORME%" echo [OK]    !NOMBRE!  !VER!
  ) else if "!ENC!"=="2" (
    echo [OK]    !NOMBRE!  instalado, pero fuera del PATH. Abre una terminal nueva.
    >>"%INFORME%" echo [OK]    !NOMBRE!  instalado, pero fuera del PATH. Abre una terminal nueva.
  ) else (
    if "!OBL!"=="1" set /a FALTAN+=1
    echo [FALTA] !NOMBRE!  id winget: !ID!
    >>"%INFORME%" echo [FALTA] !NOMBRE!  id winget: !ID!
  )
)

echo.
>>"%INFORME%" echo.
set "DOCKERLOCAL="
where docker >nul 2>&1
if not errorlevel 1 set "DOCKERLOCAL=1"
if defined DOCKERLOCAL (
  echo [INFO]  Docker local encontrado, es opcional. En el curso se usa Docker dentro de Codespaces.
  >>"%INFORME%" echo [INFO]  Docker local encontrado, es opcional. En el curso se usa Docker dentro de Codespaces.
) else (
  echo [INFO]  Docker local no instalado: correcto. En el curso se usa Docker dentro de Codespaces.
  >>"%INFORME%" echo [INFO]  Docker local no instalado: correcto. En el curso se usa Docker dentro de Codespaces.
)

echo.
>>"%INFORME%" echo.
if "!FALTAN!"=="0" (
  echo Resultado: todo lo obligatorio esta instalado.
  >>"%INFORME%" echo Resultado: todo lo obligatorio esta instalado.
) else (
  echo Resultado: faltan !FALTAN! herramientas obligatorias. Si acabas de instalar, cierra y abre la terminal y repite con: instalar_entorno.cmd verificar
  >>"%INFORME%" echo Resultado: faltan !FALTAN! herramientas obligatorias. Si acabas de instalar, cierra y abre la terminal y repite con: instalar_entorno.cmd verificar
)
echo.
echo Informe guardado en: !INFORME!
echo Pega su contenido en el diagnostico de S0 si algo falla.

Ver el script de PowerShell (instalar_entorno.ps1) 
<#
.SYNOPSIS
  Instala o verifica el software local del curso "ML e IA: de desarrollo a produccion" en Windows.

.DESCRIPTION
  ESTADO: la sintaxis se valido con el analizador de PowerShell 7 y la logica se probo en Linux con un winget
  falso (deteccion, instalacion, confirmacion e informe). NO se ha probado en Windows real, ni en Windows
  PowerShell 5.1, ni con winget real. Probarlo en un equipo limpio antes de entregarlo a los alumnos y
  confirmar los identificadores de paquete con: winget search <nombre>

  Que hace (y solo esto):
    - Usa winget (el administrador de paquetes de Windows) para instalar: Git, Visual Studio Code, Miniconda,
      DB Browser for SQLite y Google Cloud CLI.
    - Instala las extensiones de VS Code del curso (si VS Code ya esta disponible).
    - Con -Verificar no instala nada: solo comprueba y escribe un informe.
  No descarga nada que no sea de winget. No modifica el registro ni la politica de ejecucion del equipo.
  No pide ni guarda contrasenas, tokens o claves.

  Docker y Kubernetes NO se instalan: en el curso se usan dentro de Codespaces.
  Docker Desktop local es opcional (-ConDockerDesktop).

.PARAMETER Verificar
  Solo comprueba lo instalado y genera el informe. No instala nada.

.PARAMETER ConDockerDesktop
  Instala tambien Docker Desktop (opcional, no es requisito del curso).

.PARAMETER SinConfirmacion
  No pregunta antes de instalar cada programa.

.PARAMETER SinExtensiones
  No instala las extensiones de VS Code.

.EXAMPLE
  powershell -ExecutionPolicy Bypass -File .\instalar_entorno.ps1
  powershell -ExecutionPolicy Bypass -File .\instalar_entorno.ps1 -Verificar
#>
[CmdletBinding()]
param(
    [switch]$Verificar,
    [switch]$ConDockerDesktop,
    [switch]$SinConfirmacion,
    [switch]$SinExtensiones
)

$ErrorActionPreference = 'Continue'
$informe = Join-Path (Get-Location) 'verificacion-entorno.txt'

# ---------------------------------------------------------------- utilidades
function Actualizar-Path {
    # winget deja el PATH actualizado en el sistema, pero no en esta ventana.
    $m = [Environment]::GetEnvironmentVariable('Path', 'Machine')
    $u = [Environment]::GetEnvironmentVariable('Path', 'User')
    $env:Path = "$m;$u"
}

function Buscar-Comando {
    param([string]$Nombre, [string[]]$RutasAlternativas = @())
    $cmd = Get-Command $Nombre -ErrorAction SilentlyContinue
    if ($cmd) { return $cmd.Source }
    foreach ($r in $RutasAlternativas) {
        $ruta = [Environment]::ExpandEnvironmentVariables($r)
        if (Test-Path $ruta) { return $ruta }
    }
    return $null
}

function Obtener-Version {
    param([string]$Ejecutable, [string[]]$Argumentos)
    try {
        $salida = & $Ejecutable @Argumentos 2>&1 | Select-Object -First 1
        return ([string]$salida).Trim()
    } catch {
        return 'no se pudo leer la version'
    }
}

# ---------------------------------------------------------------- herramientas
# Id = identificador de winget. Comprobar con: winget search <nombre>
$herramientas = @(
    @{ Nombre = 'Git';                    Id = 'Git.Git';                                  Comando = 'git';
       Alternativas = @('%ProgramFiles%\Git\cmd\git.exe');
       Version = @('--version'); Obligatoria = $true },
    @{ Nombre = 'Visual Studio Code';     Id = 'Microsoft.VisualStudioCode';               Comando = 'code';
       Alternativas = @('%LOCALAPPDATA%\Programs\Microsoft VS Code\bin\code.cmd', '%ProgramFiles%\Microsoft VS Code\bin\code.cmd');
       Version = @('--version'); Obligatoria = $true },
    @{ Nombre = 'Miniconda';              Id = 'Anaconda.Miniconda3';                      Comando = 'conda';
       Alternativas = @('%USERPROFILE%\miniconda3\Scripts\conda.exe', '%LOCALAPPDATA%\miniconda3\Scripts\conda.exe', '%ProgramData%\miniconda3\Scripts\conda.exe');
       Version = @('--version'); Obligatoria = $true },
    @{ Nombre = 'DB Browser for SQLite';  Id = 'DBBrowserForSQLite.DBBrowserForSQLite';   Comando = 'DB4S-no-esta-en-PATH';
       Alternativas = @('%ProgramFiles%\DB Browser for SQLite\DB Browser for SQLite.exe');
       Version = $null; Obligatoria = $true },
    @{ Nombre = 'Google Cloud CLI';       Id = 'Google.CloudSDK';                          Comando = 'gcloud';
       Alternativas = @('%LOCALAPPDATA%\Google\Cloud SDK\google-cloud-sdk\bin\gcloud.cmd', '%ProgramFiles(x86)%\Google\Cloud SDK\google-cloud-sdk\bin\gcloud.cmd');
       Version = @('--version'); Obligatoria = $true }
)
if ($ConDockerDesktop) {
    $herramientas += @{ Nombre = 'Docker Desktop (opcional)'; Id = 'Docker.DockerDesktop'; Comando = 'docker';
       Alternativas = @('%ProgramFiles%\Docker\Docker\resources\bin\docker.exe');
       Version = @('--version'); Obligatoria = $false }
}

# Extensiones de VS Code del curso. Comprobar con: code --list-extensions
$extensiones = @(
    'ms-python.python',
    'ms-python.vscode-pylance',
    'ms-toolsai.jupyter',
    'ms-azuretools.vscode-containers',
    'ms-kubernetes-tools.vscode-kubernetes-tools',
    'ms-vscode-remote.remote-containers',
    'GitHub.codespaces'
)

# ---------------------------------------------------------------- inicio
Write-Host ''
Write-Host '=== Entorno del curso ML e IA (Windows) ===' -ForegroundColor Cyan
if ($Verificar) { Write-Host 'Modo verificacion: no se instala nada.' -ForegroundColor Yellow }
else { Write-Host 'Modo instalacion. Lee lo que hace este script antes de continuar.' -ForegroundColor Yellow }
Write-Host ''

$winget = Get-Command winget -ErrorAction SilentlyContinue
if (-not $Verificar -and -not $winget) {
    Write-Host 'No se encontro winget. Instala "Instalador de aplicacion" desde Microsoft Store, o sigue la guia manual con descargas.' -ForegroundColor Red
    exit 1
}

# ---------------------------------------------------------------- instalacion
if (-not $Verificar) {
    foreach ($h in $herramientas) {
        $ruta = Buscar-Comando -Nombre $h.Comando -RutasAlternativas $h.Alternativas
        if ($ruta) {
            Write-Host ("[ya instalado] {0}" -f $h.Nombre) -ForegroundColor Green
            continue
        }
        if (-not $SinConfirmacion) {
            $resp = Read-Host ("Instalar {0}? (s/N)" -f $h.Nombre)
            if ($resp -notmatch '^[sSyY]') { Write-Host ("[omitido] {0}" -f $h.Nombre); continue }
        }
        Write-Host ("[instalando] {0} ({1})..." -f $h.Nombre, $h.Id) -ForegroundColor Cyan
        & winget install --id $h.Id -e --accept-source-agreements --accept-package-agreements
        if ($LASTEXITCODE -ne 0) {
            Write-Host ("[fallo] {0}: winget devolvio el codigo {1}. Prueba la instalacion manual de la guia." -f $h.Nombre, $LASTEXITCODE) -ForegroundColor Red
        }
    }
    Actualizar-Path

    if (-not $SinExtensiones) {
        $code = Buscar-Comando -Nombre 'code' -RutasAlternativas @('%LOCALAPPDATA%\Programs\Microsoft VS Code\bin\code.cmd', '%ProgramFiles%\Microsoft VS Code\bin\code.cmd')
        if ($code) {
            foreach ($e in $extensiones) {
                Write-Host ("[extension] {0}" -f $e)
                & $code --install-extension $e --force | Out-Null
            }
        } else {
            Write-Host 'VS Code no esta disponible todavia: cierra y abre la terminal y vuelve a ejecutar el script para instalar las extensiones.' -ForegroundColor Yellow
        }
    }
    Write-Host ''
}

# ---------------------------------------------------------------- verificacion e informe
Actualizar-Path
$lineas = New-Object System.Collections.Generic.List[string]
$lineas.Add('Informe de verificacion del entorno - curso ML e IA')
$lineas.Add(('Fecha: {0}' -f (Get-Date -Format 'yyyy-MM-dd HH:mm')))
$lineas.Add(('Windows: {0}' -f [Environment]::OSVersion.VersionString))
$lineas.Add(('PowerShell: {0}' -f $PSVersionTable.PSVersion))
$lineas.Add('No incluye credenciales ni datos personales.')
$lineas.Add('')

$faltan = 0
foreach ($h in $herramientas) {
    $ruta = Buscar-Comando -Nombre $h.Comando -RutasAlternativas $h.Alternativas
    if ($ruta) {
        $ver = ''
        if ($h.Version) { $ver = Obtener-Version -Ejecutable $ruta -Argumentos $h.Version }
        $lineas.Add(('[OK]    {0}  {1}' -f $h.Nombre, $ver))
    } else {
        if ($h.Obligatoria) { $faltan++ }
        $lineas.Add(('[FALTA] {0}  (id winget: {1})' -f $h.Nombre, $h.Id))
    }
}

# Extensiones de VS Code
$codeRuta = Buscar-Comando -Nombre 'code' -RutasAlternativas @('%LOCALAPPDATA%\Programs\Microsoft VS Code\bin\code.cmd', '%ProgramFiles%\Microsoft VS Code\bin\code.cmd')
if ($codeRuta) {
    $instaladas = @(& $codeRuta --list-extensions 2>$null)
    foreach ($e in $extensiones) {
        if ($instaladas -contains $e) { $lineas.Add(('[OK]    extension {0}' -f $e)) }
        else { $lineas.Add(('[FALTA] extension {0}' -f $e)) }
    }
}

# Docker y Kubernetes: no se exigen en local
$lineas.Add('')
$dockerLocal = Buscar-Comando -Nombre 'docker' -RutasAlternativas @('%ProgramFiles%\Docker\Docker\resources\bin\docker.exe')
if ($dockerLocal) { $lineas.Add('[INFO]  Docker local encontrado (opcional). En el curso se usa Docker dentro de Codespaces.') }
else { $lineas.Add('[INFO]  Docker local no instalado: correcto. En el curso se usa Docker dentro de Codespaces.') }

$lineas.Add('')
if ($faltan -eq 0) { $lineas.Add('Resultado: todo lo obligatorio esta instalado.') }
else { $lineas.Add(('Resultado: faltan {0} herramientas obligatorias. Si acabas de instalar, cierra y abre la terminal y repite con -Verificar.' -f $faltan)) }

$lineas | ForEach-Object {
    if ($_.StartsWith('[OK]')) { Write-Host $_ -ForegroundColor Green }
    elseif ($_.StartsWith('[FALTA]')) { Write-Host $_ -ForegroundColor Red }
    else { Write-Host $_ }
}
$lineas | Set-Content -Path $informe -Encoding UTF8
Write-Host ''
Write-Host ("Informe guardado en: {0}" -f $informe) -ForegroundColor Cyan
Write-Host 'Pega su contenido en el diagnostico de S0 si algo falla.'
