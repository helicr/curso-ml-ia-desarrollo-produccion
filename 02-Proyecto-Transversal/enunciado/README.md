# Caso transversal: marco de trabajo

Dataset y problema definitivos: pendientes.

El docente demuestra un caso; el asistente reproduce y adapta otro de estructura similar.
Cada avance presenta: resultado, ejecución, pruebas, una decisión, dificultades y pasos reproducibles.

## Entregas
1. Pipeline de datos, modelo y métricas (revisión S2).
2. API y contenedor (S3).
3. Despliegue y módulo neuronal (S4).
4. Aplicación LLM y limitaciones (S5).
5. Repositorio e informe finales (posterior a S5).

No publicar datos sensibles ni secretos. No evaluar solo mediante capturas.
